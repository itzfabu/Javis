## What actually works

**1. Service arbitrage (fastest to start)**
You use AI tools to do a service faster/cheaper than competitors, sell the *outcome* not the AI part.
- Copywriting/content for local businesses (blogs, email newsletters, product descriptions)
- Video editing/repurposing (long-form → shorts) using AI transcription + editing tools
- Data cleanup, research reports, competitive analysis for small businesses
- Reality check: clients pay for the result. If you say "I use ChatGPT," you sound replaceable. If you say "I write your weekly newsletter for $400/month," you sound like a vendor.

**2. Building small tools for a specific painful problem**
Not "an AI app" — a boring tool that saves someone time.
- A Chrome extension, a Zapier-style automation, a scraper + summarizer for a niche (real estate comps, job listings, court filings)
- Sell to 20-50 people at $10-30/month. Not viral, just useful.
- The bar isn't "impressive AI," it's "does this save someone 2 hours a week."

**3. Using AI to scale a skill you already have**
If you already do consulting, design, tutoring, or freelance writing — AI lets you take on 2-3x the clients at the same quality. This is the most reliable path because you're not learning a new business model, just increasing throughput.

**4. Freelancing on upwork/fiverr, AI-assisted**
Still works, but oversaturated with low-effort output. You win by being fast *and* actually editing/verifying AI output so it doesn't read like slop.

## What to be skeptical of
- "Prompt engineering" as a standalone paid skill — mostly dead as a business model
- Reselling ChatGPT wrapper apps with no real differentiation — thousands of these already exist and fail
- Courses that teach you to sell courses about AI — the actual red flag pattern
- "Passive income" AI YouTube automation channels — real work, thin margins, saturated

## Honest bar for success
None of this is passive. The AI speeds up execution; it doesn't replace having a real customer problem to solve. The people making real money are usually doing #3 or #1 — using AI as leverage on something they can already sell, not inventing a new "AI business" from scratch.

## 3. Micro-SaaS / tools-as-websites
This is probably the strongest AI-era opportunity.
- Build a simple, useful web tool (a calculator, converter, generator, small automation) for a specific audience

- AI coding tools (Claude Code, v0, Cursor) make it realistic to actually ship this solo in days, not months
- The hard part was never "can I build it" — it's finding a real, narrow problem people will pay to solve. That part AI doesn't do for you.

Still viable in specific niches (software comparisons, local services directories) but requires genuine traffic — which requires either SEO (slow, competitive) or an existing audience (newsletter, social following) to point at it.

## What actually creates the "animated site" look

**1. CSS-based animation (the foundation, works for 80% of what you see)**
- CSS transitions/keyframes, `transform`, `opacity` — smooth hover states, fades, slides
- Scroll-triggered reveals (elements fading/sliding in as you scroll) — very common in modern landing pages
- Libraries: **Framer Motion** (React), **GSAP** (framework-agnostic, industry standard for complex sequencing), **AOS** (Animate On Scroll, simplest option)

**2. Interactive/3D elements**
- **Three.js** — 3D scenes, particle effects, product renders that rotate/respond to mouse
- **Lottie** — renders After Effects animations as lightweight web animations (this is huge for that "produced by a studio" look without hand-coding it)
- **Rive** — similar idea, interactive vector animations

**3. The video/motion-graphic layer**
This is where tools like Higgsfield come in — that's not website code, it's AI-generated *video* (like the clip you showed me) that then gets embedded as a background video or hero asset, same as any `<video>` tag. It's not "the website is animated," it's "there's a slick video file sitting in the hero section."

## Realistic path to actually build this

1. **Learn the CSS animation fundamentals first** — transitions, transforms, `@keyframes`. This alone gets you most of the polish people notice.
2. **Pick one animation library and go deep** — GSAP if you want scroll-triggered sequences and precise control (most professional sites use it), Framer Motion if you're in React.
3. **Use Claude Code (or me, right here) to build and iterate** — describe the effect you want ("hero text that fades in word by word as you scroll"), get real code, tweak it. This is genuinely the fast path — AI coding tools are good at animation code because it's well-documented and pattern-heavy.
4. **For video/motion assets** — if you want a slick background video or product animation without hiring a motion designer, that's where AI video generation tools fit in, as a separate asset, not "website code."
